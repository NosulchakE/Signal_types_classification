## Описание проекта

Целью данной работы является автоматическая кластеризация сигналов, полученных со сцинтилляционного детектора, на основе их параметров. Необходимо разделить 23 479 сигналов на три кластера: два из них соответствуют различным типам частиц (гамма-кванты и нейтроны), а третий — группе аномальных или неидентифицируемых сигналов.
Задача решается методами машинного обучения без учителя с последующей интерпретацией результатов кластеризации.

## Данные
Исходный датасет содержит 504 признака, часть из которых коррелирована. Предобработка включала удаление стационарных столбцов и масштабирование признаков с помощью StandardScaler.

## Методология
Для снижения размерности применён метод главных компонент (PCA), позволивший сократить число признаков, уменьшить шум и улучшить качество кластеризации. Кластеризация выполнена алгоритмом KMeans.

## Особенности подхода:

кластеризация на 2 основных кластера

третий кластер формируется из шумовых и сомнительных объектов

выполнена перенумерация кластеров для соответствия целевым меткам

## Результаты
Стартовая метрика на лидерборде составила 0.533. Модель может использоваться как базовая.
